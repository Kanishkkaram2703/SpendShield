# Synthetic Dataset Version Comparison

`v1_vs_v2_comparison.json` and `v1_vs_v2_comparison.md` compare the preserved
v1 artifact with the revised v2 artifact. The comparison includes version
metadata, distributions, temporal ranges, feature means, shortcut rates,
baseline metrics, per-class recall, false-positive/false-negative measures,
reproducibility, and leakage status.

Both versions remain synthetic research artifacts. The comparison does not
establish real fraud performance or select a production model.
